# Shared-host lineage review request

This is the prioritized human handoff for the 23 high-priority shared hosts in
`host-dependence-review-queue.json`. A shared host is a lineage warning, not an
independent source family. This review does not grant rights or promote a
trend.

## Required review fields

For each host, record:

- publisher or publishers controlling the artifact;
- upstream dataset, report, or event identity;
- whether URLs are restatements or distinct measurements;
- rights route and storage/transformation/redistribution scope;
- independence disposition (`independent`, `dependent`, `restatement`, or
  `insufficient_evidence`); and
- reviewer, date, evidence link, and next action.

Do not count a host as independent confirmation until all fields are reviewed.

- Host-level review completed with source URLs and upstream identity
- Shared-dataset or restatement dependence recorded

- Independence disposition entered in the machine-readable queue
- Second reviewer checks the highest-volume hosts first

`source_steward` → `rights_and_privacy_owner`. Until review is complete, shared
host repetition must not be counted as independent confirmation.
