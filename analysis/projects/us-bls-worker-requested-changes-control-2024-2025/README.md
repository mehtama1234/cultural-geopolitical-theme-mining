# Project: Worker-requested changes and job-level control

## Question

When workers need a change to make work usable, what is requested, what is
granted, and how does that differ from the underlying control structure of the
job?

## Bounded result

The [machine-readable record](../../records/us-bls-worker-requested-changes-control-2024-2025.json)
shows 5.9 million workers requesting or making changes in July 2024, with
schedule, equipment, task, telework, training, and accessibility requests
receiving different full/partial/no-grant outcomes. BLS ORS then shows that
pause control, self-paced workload, and schedule variability are separate
job-level structures in 2025.

Neither source proves that a granted change was adequate, durable, fairly
distributed, or protective of household security.

## Decisive next evidence

Link the same worker and workplace through request reason, decision timing,
actual use, pay/hours, health, care, retention, voice, and exit; preserve the
ORS occupation-level estimates as context rather than as individual outcomes.
