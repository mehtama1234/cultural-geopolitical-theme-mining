# Childhood SSI, family resources, and later outcomes

This project studies how a disability benefit reaches a child through the whole
household: money, parental work, parent time, care, and later human-capital
outcomes.

The first bounded finding uses NBER Working Paper 35725. Using Social Security
administrative data and two quasi-experiments, it reports that childhood SSI
helps when it increases household income, but effects are zero or negative when
parents offset the benefit by reducing earnings. The result separates a benefit
from the household's net resources rather than treating receipt as the whole
intervention.

## Next test

The decisive extension is a protected family-year ledger joining eligibility,
benefit amount, parental work and time, care needs, health, school, household
income, expenses, stress, services, adult earnings, disability, and later
security.
