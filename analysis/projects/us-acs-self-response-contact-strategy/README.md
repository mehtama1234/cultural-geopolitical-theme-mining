# ACS self-response and public participation

This project treats survey response as an institutional participation route.
The Census review shows that layout, messaging, reminders, and response mode
can change participation, but response improvement is partial and does not
automatically establish equal representation, trust, or later policy feedback.

See the [bounded finding](findings/us-census-acs-self-response-contact-strategy-2005-2025-001.md)
