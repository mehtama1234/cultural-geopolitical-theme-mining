# Project: Trans-Pacific cable resilience and geopolitical legitimacy

This project follows a shared infrastructure chain:

```text
cable dependence and route concentration
  -> breakage, suspected disruption, or capacity stress
  -> detection, attribution, repair, and rerouting
  -> service continuity, cost allocation, and public communication
  -> deterrence, trust, sovereignty, and external behavior
```

It complements the existing European maritime exercise finding by adding a
modeled trans-Pacific network and Pacific-island exposure. Modeled headroom is
not an outage, and a suspected gray-zone risk is not attribution.

## Ongoing question

When does cable redundancy become real public and economic resilience rather
than only modeled capacity, strategic concern, or infrastructure investment?

## Next test

rerouting, service continuity, affected users and firms, cost allocation,
public communication, and later deterrence or trust. Keep exercises, modeled
scenarios, accidental damage, and confirmed hostile action separate.
