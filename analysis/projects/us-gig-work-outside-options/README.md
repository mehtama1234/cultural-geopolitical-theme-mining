# Project: gig work and outside options

## Question

When a worker can use another platform, does that create a real alternative
or merely another place to supply labor?

## Decision rule

Keep platform access, attempted switching, labor supply, pay, net costs, hours,
control, bargaining power, and household security separate. A second app is not
automatically a usable exit.

## Current bounded finding

The [outside-options finding](findings/us-nber-gig-economy-outside-options-labor-supply-2026-001.md)
reports that competitor access increased Uber drivers' responsiveness to the
firm and lowered the implied monopsony markdown. Net earnings and durable
security remain open.
