# Harness and RL environments

This is the dedicated project folder for the long-term Harness/RL-environment
research goal. It keeps the cultural/geopolitical analysis repo separate from
the executable research-signals run while linking the two evidence layers.

The canonical six-month capture and pipeline outputs are in the sibling repo:

`../research-signals/data/runs/harness-rl-environments-six-month-20261017/`

That run covers 2026-04-17 through 2026-10-17 and currently contains 276
reclassified social records, seven ArXiv candidates, ten facets, a primary
source matrix, a survey review, and a cross-facet synthesis. Its own audit
correctly marks the package as a candidate package rather than final completion.

The cultural-research layer will use this project folder for the durable goal,
survey comparison, cross-domain interpretation, and the next verification queue.

## Current finding

The literature treats the harness as part of the learning system: it chooses
what the agent sees, stores, verifies, retries, and records. The key unresolved
question is whether reported gains transfer across models, tasks, and held-out
environments once cost, safety, permissions, and recovery are matched.

## Evidence boundary

LinkedIn and other social posts are adoption and framing signals. ArXiv papers,
repositories, benchmark artifacts, and reruns are the evidence for technical
claims. The two must remain linked but not conflated.
