# Project: Public pensions, private equity, and firm productivity

This project follows a financial-institution pathway from public pension
funding pressure to private-equity matching and the firms those funds finance.
A Census CES working paper reports that more severely underfunded public
pensions receive lower average private-equity returns, match with smaller
general partners, and finance firms that experience labor-productivity
decreases.

The safe theme is not “public pensions cause worker decline.” Funding status,
governance, investment choice, fund quality, firm selection, and sector may be
connected. The project keeps pension returns, fund matching, firm productivity,
employment, wages, worker control, and beneficiary security separate.

The decisive next artifact is a protected pension-fund-firm-worker ledger
joining funding status, mandate, investment, fund, target firm, productivity,
employment, pay, hours, survival, pension returns, and beneficiary outcomes.
The current paper does not close that full chain.
