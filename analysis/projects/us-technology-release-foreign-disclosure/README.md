# Project: Foreign defense technology release and partner trust

## Question

When a foreign partner asks the United States for sensitive military
technology, how does the permission process shape speed, control, and the
relationship?

## Decision rule

Keep the request, review, approval or denial, transfer, delivery, use,
sustainment, and partner response separate. Faster approval is not automatically
better security, and a formal request is not a completed capability.

## Current bounded finding

The [GAO technology-release finding](findings/us-gao-technology-release-foreign-disclosure-2026-001.md)
shows a large, specialized permission system. Most cases reportedly use
existing precedent, while new or sensitive cases can take much longer and
urgent requests can be accelerated by shifting staff and attention.

The route is:

```text
foreign partner request
  -> U.S. policy, security, and interagency review
  -> approval, redesign, delay, or denial
  -> [open] transfer and operational use
  -> [open] partner trust, dependence, cooperation, or outside response
```

The public report does not follow a named request through delivery and use.
