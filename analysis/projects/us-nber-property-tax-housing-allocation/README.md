# Project: property taxes, housing lock-in, and intergenerational allocation

This project tracks how housing tax design changes practical room across age,
wealth, and tenure groups. The first bounded record uses NBER Working Paper
35587, an overlapping-generations model of property taxes, capitalization,
financial constraints, and step-up-basis treatment.

The project treats lower prices, lower downpayments, higher holding costs,
homeownership, rental access, mobility, public services, and family transfers
as separate stages. Modeled counterfactuals are not presented as observed
policy effects or as proof that one generation simply gains at another's
expense.
