# Project: managed long-term services, cross-payer spillovers, and state design

This project tracks how Medicaid delivery design affects long-term services and
supports, care coordination, and outcomes financed by other programs. The first
bounded record uses NBER Working Paper 35055, comparing staggered managed-LTSS
rollouts in Florida and New York with administrative Medicare claims.

The project keeps payer boundary, state implementation, hospitalization,
preventive care, nursing-home use, quality, household burden, and functional
outcomes separate. A result in Florida is not treated as the effect of managed
care everywhere.
