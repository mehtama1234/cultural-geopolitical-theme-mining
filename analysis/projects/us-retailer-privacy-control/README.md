# Retailer privacy requests and practical control

This project examines the administrative middle between a consumer privacy right and a claimed result. Walmart's California metrics report requests received, completed, denied, and median processing time for access, deletion, and sale opt-out.

## Next test

Compare company-reported completion with consumer-level verification, denial reasons, residual data, re-collection, appeal, and later trust or switching, while keeping deletion, access, and sale opt-out as separate actions.
