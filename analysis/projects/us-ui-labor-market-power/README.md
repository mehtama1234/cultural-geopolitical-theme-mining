# Project: unemployment insurance, labor-market power, and job matching

## Question

Does extra time to search for work produce the same improvement everywhere, or
does local employer concentration limit the quality of the available match?

## Decision rule

Keep benefit duration, time out of work, job match, earnings, job quality,
bargaining power, household security, and later mobility separate. More search
time is not automatically a better job or greater worker control.

## Current bounded finding

The [Census CES finding](findings/us-census-ui-extensions-labor-market-concentration-match-quality-2026-001.md)
reports that UI extensions lengthened nonemployment by about one week, while
their earnings effect was weaker in more concentrated local labor markets.
This is a study-specific interaction, not a universal measure of employer
power or worker welfare.
