# Aggregate shocks, preferences, and beliefs

This project tracks a review of evidence on how recessions, inflation, trade,
migration, war, terrorism, pandemics, and disasters can shape preferences,
risk attitudes, and institutional trust. It is a map of heterogeneous studies,
not a new pooled estimate.
