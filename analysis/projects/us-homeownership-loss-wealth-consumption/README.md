# Homeownership loss, housing wealth, and consumption

This project studies the difference between keeping a home, gaining housing
wealth, and having more usable household room after mortgage distress.

The first bounded finding uses NBER Working Paper 33692. Among seriously
delinquent Great Recession homeowners, mortgage modification produced a large
and persistent increase in home retention and about $70,000 more housing wealth,
but did not raise consumption because credit constraints limited borrowing
against equity. The result is a conversion counterexample, not an argument that
housing wealth has no value.

## Next test

The decisive extension is a protected homeowner-year ledger joining delinquency,
modification, payment, equity, credit access, consumption, repairs, health,
neighborhood, move or stay, bequest, and later security.
