# Project: institutional ownership of single-family rentals

This project tests how firm ownership becomes housing-market and place power.
It keeps ownership counts separate from rents, repairs, eviction, tenant
stability, homeownership, neighborhood change, and practical housing exit.

The [bounded finding](findings/us-gao-institutional-rental-ownership-six-metros-2018-2024.md)
uses GAO's six-metro 2018-2024 comparison. It is a place and firm-capacity
finding, not a national estimate or a claim that institutional ownership alone
caused housing insecurity.
