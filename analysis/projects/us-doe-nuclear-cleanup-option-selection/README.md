# Project: DOE cleanup option selection and independent review

This project tests how public-project framing, contractor and regulatory
relationships, technical alternatives, and independent review shape practical
choice. It keeps mission need, option generation, cost comparison, approval,
construction, safety, cleanup, and public consequence as separate stages.

The [bounded finding](findings/us-gao-doe-nuclear-cleanup-mission-need-option-selection-2026.md)
uses a 2026 GAO review of selected Department of Energy cleanup projects. It is
not a national estimate of project waste or contractor performance.
