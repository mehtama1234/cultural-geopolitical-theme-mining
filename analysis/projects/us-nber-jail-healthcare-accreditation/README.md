# Project: jail healthcare accreditation, institutional practice, and mortality

This project tracks whether public-system quality can improve through
organizational standards, coordination, screening, and oversight when care is
delivered by contractors in a coercive institutional setting. The first
bounded record uses NBER Working Paper 33357, a randomized accreditation offer
across 46 U.S. jails.

The project keeps measured compliance, mortality, care quality, staffing,
contractor incentives, post-release health, trust, and detention exposure as
separate stages. An institutional improvement is not treated as proof of
fairness, freedom from custody, or durable recovery after release.
