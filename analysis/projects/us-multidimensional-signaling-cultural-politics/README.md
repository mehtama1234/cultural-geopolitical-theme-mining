# Multidimensional signaling and cultural politics

This project tests a narrow cultural-politics mechanism: when voters cannot
observe everything about a candidate, the issue dimension that sends the
clearest signal may receive more campaign attention. The source is a formal
NBER model, not a survey of current U.S. voters.

The safe reading is that cultural rhetoric can be politically useful even when
economic issues remain more important to voters. The model does not tell us
how common this is, whether it persuades anyone, or whether it changes policy.
