# Project: Import dependence, bargaining power, and negotiation

## Question

When one country depends more on another for strategically difficult-to-
substitute imports, does that dependence change bargaining behavior before a
trade or security dispute becomes visible?

## Short finding route

Keep asymmetric dependence, model-implied power, engagement, negotiation,
trade adjustment, threat credibility, retaliation, and strategic outcome as
separate stages. A modeled power index is not a completed coercion episode.

See the [bounded finding](findings/us-nber-international-power-negotiation-2025-001.md).
