# Project: Social Security information and disability/retirement benefit choice

This project follows a public information interface through administrative
choice: personalized statement → perceived option set → Disability Insurance
or Old-Age Insurance application → award, receipt, income, work, health, and
household security. It keeps application behavior distinct from realized
benefit access.

The first bounded finding uses NBER Working Paper 35748. Receiving an initial
Social Security statement with personalized DI and OAI estimates increased
applications among people with work-limiting health conditions or low work
ability. The response was concentrated among people further from full
retirement age, and DI growth was split between DI-only and joint applications.
