# AI exposure measurement stability

This project tests whether model-generated occupational AI-exposure measures are stable enough to support broad claims about work, inequality, and local effects. The initial source repeats the same task-rating rubric with three frontier language models and examines how downstream estimates change.

## Initial finding

- [Finding 001: AI exposure estimates can change when the measuring model changes](findings/us-nber-ai-exposure-measurement-instability-2026-001.md)

## Next test

Compare model-generated exposure measures with non-LLM task measures, worker reports, observed adoption, and realized job or earnings outcomes before using them as a common input across the atlas.
