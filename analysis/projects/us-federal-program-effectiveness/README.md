# Project: Federal program effectiveness and public feedback

## Question

Can federal agencies tell whether programs are solving the problems they were
created to fix, rather than only counting money spent or people reached?

## Decision rule

Keep inputs, outputs, outcomes, process measures, and impact evaluations
separate. A program can have a performance process without proving that it
improved people's lives, and a missing measure is not proof that the program
failed.

## Current bounded finding

The [GAO finding](findings/us-federal-program-effectiveness-001.md) shows that
many federal programs lack clear outcome goals or useful data, while a selected
set of programs had stronger performance-management processes and one DHS
program improved after earlier oversight.
