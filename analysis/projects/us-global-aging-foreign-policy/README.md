# Project: global aging and U.S. foreign-policy consequences

This project tests how demographic aging abroad can become a U.S. social,
economic, health, and geopolitical issue.

```text
population aging
  -> care and health demand, labor-pool change, migration, fiscal pressure
  -> partner-government priorities and resource allocation
  -> U.S. assistance, alliance, trade, and security choices
  -> changed cooperation, burden sharing, resilience, or leverage
```

GAO-26-108732 identifies the channels and current agency attention. It does
not follow a country through demographic change to a defense budget, alliance
decision, migration flow, or U.S. strategic outcome.
