# Project: public-building reorganization and service capacity

This project tests how institutional restructuring changes workforce capacity,
service delivery, feedback, and confidence. It keeps announced goals, staffing,
implementation, tenant experience, measured performance, and later correction
as separate stages.

The [bounded finding](findings/us-gao-public-buildings-reorganization-workforce-service-2025-2026.md)
uses a 2026 GAO review of the Public Buildings Service. It is a named agency
case, not a general estimate of federal reorganization.
