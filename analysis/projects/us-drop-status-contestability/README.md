# Project: California DROP status and practical data control

## Question

What does California's new data-deletion system make visible after a person
submits a request, and what remains hidden?

## Decision rule

Keep request submission, broker matching, status reporting, deletion, exemption,
opt-out, suppression of future collection, downstream contractor action, and
later reappearance separate. A status screen is evidence of a contestable route,
not proof that every copy of data disappeared.

## Current bounded finding

The [DROP finding](findings/us-drop-status-contestability-001.md) shows that
California gives a consumer a single request, a tracking ID, and per-broker
statuses, while mandatory processing and later rechecks still occur on broker
cycles and no public aggregate completion or downstream-control table is shown
on the official pages reviewed.
