# Fraud risk, public trust, and mission execution

This project examines fraud control as an institutional legitimacy issue as
well as a financial-control issue. It preserves the difference between GAO
recommendations, open implementation, fraud incidence, and individual trust.

## Finding

See [Finding 001](findings/us-fraud-risk-public-trust-001.md).

The current [institutional distrust, control capacity, and local agency bridge](institutional-distrust-control-capacity-local-agency-bridge-v1.md) compares Gallup, UMass, GAO, rural civic-network evidence, and bounded public discussion. It keeps perception, control work, remedy, public-system use, and local substitution as separate stages.
