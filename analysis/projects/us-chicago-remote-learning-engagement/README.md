# Project: school outreach, remote learning, and realized engagement

This project follows school-system interventions through take-up, engagement,
and later academic outcomes. It preserves the difference between a family
registering, a student using a platform, attending class, and learning.

The first bounded finding uses NBER Working Paper 34996, which reports three
randomized trials in Chicago Public Schools. Personalized calls increased
summer-program registration; weekly texts and instructional-aide support had
null primary engagement effects but some secondary or later academic gains.

See the [initial finding](findings/us-nber-chicago-remote-learning-engagement-rcts-2026-001.md)
and the [machine-readable record](../../records/us-nber-chicago-remote-learning-engagement-rcts-2026.json).

The [Young Futures to realized outcome bridge](young-futures-to-realized-outcome-bridge-v1.md)
connects this randomized take-up and later-outcome evidence to the eight-site
Young Futures Hubs implementation evaluation. It keeps registration, use,
attendance, referral, immediate experience, later outcome, and durability as
separate stages.
