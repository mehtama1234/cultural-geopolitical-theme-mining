# Project: US employment-discrimination recourse and workplace change

## Question

What does the EEOC enforcement route show about moving from a discrimination
complaint to a remedy?

## Decision rule

Keep inquiries, charges, investigations, merit findings, settlements,
monetary relief, equitable relief, litigation, compliance, and lived workplace
change separate. Agency output is not the same as durable protection for a
particular worker.

## Current bounded finding

The [EEOC finding](findings/us-employment-discrimination-recourse-001.md)
shows a large civil-rights enforcement system that resolved many charges and
secured relief while individual receipt, workplace change, and later security
remain mostly unobserved.
