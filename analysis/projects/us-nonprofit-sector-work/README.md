# Nonprofit-sector work and social infrastructure

This project examines how the labor conditions of nonprofit organizations may
shape the social infrastructure they provide. Census CES evidence finds a
large nonprofit workforce and a lower, highly heterogeneous earnings profile.
Pay, mission, worker wellbeing, service quality, and community outcomes remain
separate stages.
