# Project: federal-building accessibility and complaint visibility

This project tests whether a formal accessibility complaint route becomes
usable accountability for people who encounter barriers in federal buildings.
The first bounded source is GAO-26-108575, which reports complaint counts and
stakeholder evidence that many potential users do not know the route exists.

The central distinction is:

```text
accessibility standard and complaint route
  -> person knows the route and can use it
  -> complaint is received and processed
  -> barrier is corrected and access improves
  -> continued usable access and trust
```

The current source reaches the complaint route and awareness stages. It does
not follow a complainant through correction or later access.
