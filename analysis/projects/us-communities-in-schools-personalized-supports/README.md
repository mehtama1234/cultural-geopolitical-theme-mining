# Project: Communities In Schools and personalized long-run support

This project follows a public-school intervention through the missing middle:
personalized coordinator relationship → academic, behavioral, mental-health, or
basic-needs support → attendance and test scores → high-school completion →
adult earnings and mobility. It keeps program reach, service receipt, trust,
and long-run outcomes distinct.

The first bounded finding uses NBER Working Paper 35740. Communities In Schools
places coordinators in high-poverty schools to match struggling students with
personalized resources. A staggered rollout is associated with higher test
scores, high-school completion, and adult earnings. Test-score gains explain
about half of the graduation effect; attendance and behavior account for much
of the remainder.
