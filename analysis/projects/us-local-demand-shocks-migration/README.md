# Project: Local demand shocks, jobs, and migration

This project tracks how places respond when local labor demand changes. A
Census working paper harmonizes several annual commuting-zone shock measures
and finds that the shock definition matters: trade-related shocks show little
employment or migration response, while more general Bartik-style shocks are
associated with economically meaningful changes in both.

The safe theme is not “local shocks cause migration” or “trade shocks do
nothing.” It is that different measures may represent different local events,
and employment, migration, commuting, household adaptation, and participation
can be separate responses. The project must keep the shock measure, time
horizon, employment, migration, commuting, household security, and community
change distinct.

The decisive next artifact is a protected commuting-zone household panel joining
shock definition, industry exposure, jobs, wages, commuting, moves, housing,
family structure, benefits, local services, and later outcomes. The public
abstract does not provide that complete bridge.
