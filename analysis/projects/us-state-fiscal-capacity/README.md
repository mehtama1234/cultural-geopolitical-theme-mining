# Project: state fiscal room and public-service capacity

## Question

When state budgets still have reserves but revenue growth slows, how does that
fiscal room become an actual public service, cut, delay, tax change, or local
burden?

## Current bounded finding

The [Spring 2026 NASBO finding](findings/us-nasbo-state-budget-buffer-adjustment-2026-001.md)
shows that governors' proposed fiscal 2027 budgets were still growing only
slightly while states used targeted cuts, vacant-position reductions, revenue
changes, and prior surplus balances. This is a state-capacity signal, not a
measure of household service quality or political trust.

The [machine-readable record](../../records/us-nasbo-state-budget-buffer-adjustment-2026.json)
keeps the state-budget unit, fiscal-year clock, and public-service boundary
explicit.
