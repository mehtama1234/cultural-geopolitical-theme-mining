# Project: reusable software and firm scope

## Question

When digital capital can be reused across many sites, does it make larger firm
scope easier—and what remains unknown about the consequences?

## Decision rule

Keep software adoption, firm scope, concentration, productivity, prices, wages,
worker control, service quality, and consumer choice separate. A model that
explains more concentration does not by itself show market harm or benefit.

## Current bounded finding

The [Census CES finding](findings/us-census-nonrival-custom-software-firm-scope-concentration-2026-001.md)
reports that multi-establishment firms are more likely to adopt custom software
but devote a smaller capital share to it, and models how falling software costs
can support greater scope and concentration. The downstream social effects are
open.
