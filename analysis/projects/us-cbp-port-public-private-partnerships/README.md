# Project: CBP ports, private funding, and public border capacity

## Question

When private partners pay for extra port service or donate port equipment,
what does that show about public capacity and who carries the cost?

## Decision rule

Keep traffic scale, partnership agreements, reimbursement, donations, staffing,
inspection decisions, queue performance, cargo release, traveler experience,
and public accountability separate. More funded capacity is not automatically
faster, fairer, or better border service.

## Current bounded finding

The [GAO port-partnership finding](findings/us-gao-cbp-public-private-port-partnerships-2026-001.md)
shows a very large public border system using private reimbursement and donated
infrastructure to add capacity. The route is:

```text
high passenger and cargo demand
  -> public inspection system
  -> partner-funded overtime or donated equipment
  -> [open] faster, fairer, safer, or cheaper processing
  -> [open] traveler, carrier, local, and geopolitical effects
```

The evidence does not show that partnership dollars changed a particular
person's wait, a shipment's release, or a port's accountability.
