# Connected-vehicle data control and service trade-offs

This project examines whether a formal privacy right remains usable when turning off data collection may affect valued connected-vehicle services. The FTC order and GM privacy statement provide a named firm and explicit control surfaces, while leaving actual consumer use and outcome open.
