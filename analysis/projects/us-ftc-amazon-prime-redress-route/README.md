# Project: Amazon Prime redress, receipt, and consumer control

## Question

When a platform settlement automatically issues money to eligible consumers,
which remedy stages are visible, and which remain unobserved?

## Short finding route

The FTC's Amazon Prime settlement update provides an aggregate issuance stage
and a lower-burden automatic distribution design. It does not show whether a
given consumer received or accepted the payment, corrected the account,
cancelled, stayed, switched, or recovered. See the [bounded finding](findings/us-ftc-amazon-prime-redress-route-2026-001.md).
