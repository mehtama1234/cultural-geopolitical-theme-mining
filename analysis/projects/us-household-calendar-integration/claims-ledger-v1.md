# Household calendar integration claims ledger v1

This ledger is for the proposed twelve-month study. A connected finding is not the same as a result observed in the same household. `cross-topic support` means the existing project records point to the mechanism from separate studies. `panel test` means the claim must be tested with joined household records.

## Ledger rules

1. Do not upgrade `cross-topic support` to household evidence because several pages use the same words.
2. Record the source population, date, geography, method, and limitation before using a result.
3. Keep a separate row for the household event, the institutional decision, and the later outcome.
4. Mark a claim `reported` when it comes only from a participant and `observed` when a permitted record confirms it.
5. Add at least one counterexample to each tested claim before writing a causal conclusion.
6. If a field is missing, write `unknown`; do not infer zero, no harm, or recovery.
