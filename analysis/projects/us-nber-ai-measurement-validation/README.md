# Project: AI measurement, validation, and institutional legitimacy

This project tracks how AI changes the measurement layer beneath public,
firm, platform, and research decisions. The first bounded record uses NBER
Working Paper 35744, which argues that AI makes structured measurement from
unstructured data cheaper while shifting the central problem toward construct
definition and validation.

The project keeps measurement scale separate from measurement validity,
institutional legitimacy, and downstream effects on people. Future passes
should test named systems, validation samples, error distributions, affected
subgroups, appeal routes, and whether measured visibility changes resource or
decision allocation.
