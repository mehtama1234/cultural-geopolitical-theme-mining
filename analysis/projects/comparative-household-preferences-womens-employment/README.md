# Comparative project: household preferences and women’s employment

This project uses comparative evidence to test whether household beliefs about
women’s work are fixed or experience-sensitive. It follows work assignment →
individual and partner wellbeing → later employment preference and concern,
while keeping the Bangladesh evidence separate from U.S. household estimates.

The first bounded finding uses NBER Working Paper 34969. A randomized six-week
job assignment found that women’s work improved women’s own wellbeing but not
their husbands’, while men’s work improved both partners’ wellbeing. One year
later, households in which women had worked were more likely to prefer a woman
take a job and reported fewer concerns about women’s employment.
