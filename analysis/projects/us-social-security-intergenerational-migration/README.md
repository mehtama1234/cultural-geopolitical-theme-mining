# Project: Social Security, caregiving substitution, and intergenerational mobility

This project follows an institutional transfer through family support,
geographic mobility, labor-market matching, and long-run housing outcomes. It
keeps sons' and daughters' pathways distinct rather than treating family care
as a uniform response.

The first bounded finding uses NBER Working Paper 35456. Greater predicted
parental Social Security coverage is associated with sons moving farther from
their childhood homes, earning more, and living in better neighborhoods later
in life; comparable effects were not found for daughters.
