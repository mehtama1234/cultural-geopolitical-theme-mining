# Project: Information encounters, correction, and civic trust

This project follows the information-legitimacy route across the atlas:

```text
news encounter / AI summary / creator post
  -> source judgment and verification
  -> correction, accountability, or silence
  -> civic conversation or action
  -> durable trust, switching, avoidance, or exit
```

The existing evidence is strong on discovery, platform reach, source trust,
and public norms. It is still weak on the middle: whether a person checks a
claim, sees a correction, changes a judgment, contacts an institution, or
leaves a source. This is a separate information-legitimacy lane, not a claim
that media exposure causes political behavior.

## Current bridge

- [Information encounter to civic trust bridge](information-encounter-correction-civic-trust-bridge-v1.md)

## Ongoing question

When does intermediary-led information discovery become durable civic agency,
and when does it instead produce confusion, silence, distrust, or exit?

## Next test

Find one bounded controversy or local-information episode with a dated first
claim, identifiable source, verification or correction event, audience
response, and later civic or source-choice outcome. Keep passive exposure,
belief, sharing, official contact, voting, protest, and source exit as separate
fields. The program must retain people who did not encounter, verify, act, or
switch as denominators where the source supports them.
