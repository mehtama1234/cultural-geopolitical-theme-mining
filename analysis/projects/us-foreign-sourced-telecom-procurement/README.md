# Project: foreign-sourced telecommunications procurement and information control

This project tests how a national-security procurement rule becomes an
operating supply-chain control across agencies and contractors.

```text
statutory prohibition
  -> agency screening and contractor representation
  -> affiliate/origin information
  -> purchase, substitution, or waiver
  -> equipment actually absent or controlled
  -> operational security and public consequences
```

GAO-26-108630 reaches the prohibition, screening, and information-sharing
stages. It does not observe equipment-level verification, avoided incidents,
operational effects, or strategic leverage.
