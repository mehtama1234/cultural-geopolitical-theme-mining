# Project: Justice usability and legitimacy

This project follows the justice pathway from institutional capacity to lived
access:

```text
legal problem
  -> information, cost, distance, and time
  -> statutory, customary, digital, or non-use pathway
  -> fair and timely resolution
  -> remedy, safety, trust, repeat use, or exit
```

The atlas already measures public-system throughput and program reach in many
domains. Justice is a useful test because a court can clear cases while users
are discouraged by delay, missing information, travel, or weak follow-up. The
project keeps internal performance, practical access, fairness, resolution,
and legitimacy separate.

## Ongoing question

When does institutional justice capacity become usable, fair, and trusted
resolution rather than only high internal throughput?
