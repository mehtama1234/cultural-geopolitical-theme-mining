# Project: international commitments and usable oversight

This project tests how U.S. international agreements move from executive action
to congressional visibility, public discoverability, partner understanding, and
later implementation. It keeps formal commitment, reporting, publication,
searchability, oversight, operation, and legitimacy as separate stages.

The [bounded finding](findings/us-gao-international-commitment-reporting-transparency-2023-2025.md)
uses a 2026 GAO audit of State Department reporting and publication. It is not
a judgment about the merits of any individual agreement.
