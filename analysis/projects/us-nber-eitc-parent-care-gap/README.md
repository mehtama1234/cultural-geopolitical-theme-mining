# Project: EITC work incentives and the family-care gap

## Question

When a work-contingent benefit changes an adult daughter's incentive to work,
what happens to the care her older parent receives, and does another person,
money, or paid provider replace it?

## Short finding route

Keep EITC generosity, daughter work, parent care, intensive-care loss,
financial transfers, substitute family care, paid care, care quality, and health
as separate stages. A work gain can coexist with an unfilled care gap.
