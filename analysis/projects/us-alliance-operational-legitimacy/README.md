# Project: Alliance operations, attribution, and public legitimacy

## Question

When an alliance moves from standing posture to a real operation, does the
action create durable security and public permission—or only a visible episode
before attribution, burden-sharing, and deterrence are known?

## Short end-to-end goal

Follow one named alliance incident from readiness and host-nation support
through detection, action, attribution, information contest, local burden,
public judgment, and later capability or adversary response.

```text
standing posture or threat
  -> named asset, host, and operation
  -> detection, interception, protection, or disruption
  -> attribution and information contest
  -> public judgment, burden-sharing, and local acceptance
  -> later capability, deterrence, escalation, or policy response
```

This is a separate geopolitical depth lane in the ongoing 14-theme program. It
keeps official capability claims, survey legitimacy, and public discussion as
different evidence layers.

## Current bridge

The [alliance operation-to-legitimacy bridge](alliance-operation-attribution-legitimacy-bridge-v1.md)
uses the 2026 Lithuania drone interception, NATO ISR operations, resilience
requirements, G7 information-contest reporting, and Pew's 37-country survey.
It finds that operational response is visible before deterrence, local burden,
and willingness to sustain the alliance are measured.

## Next test

The next qualifying record is an incident-level ledger with sensor or event
time, asset and host, action, cost/readiness effect, civilian exposure,
independent attribution, public response, and a later change in posture,
incident frequency, or partner behavior.
