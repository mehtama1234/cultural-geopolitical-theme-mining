# The politics of workplace AI

This project separates political identity from occupational and educational sorting in workplace AI use, then checks whether perceived job-displacement risk follows the same pattern.

## Initial finding

- [Finding 001: Partisan differences in workplace AI use are largely about where people work](findings/us-nber-politics-ai-partisan-composition-2026-001.md)

## Next test

Use repeated worker-level measures to test whether the emerging displacement-risk gap persists, changes with workplace exposure, or predicts political attribution and action.
