# Flood buyouts, race, and relocation

This project studies the social route behind managed retreat: the property
valuation, compensation, move, destination neighborhood, and later security
that follow a federal flood buyout.

The first bounded finding uses NBER Working Paper 35726. It combines federal
property acquisitions, housing sales, restricted-use Census data, and individual
movement records. The paper reports lower compensation for households of color
and different post-buyout neighborhood outcomes for White and Black
participants. This is a policy-distribution finding, not proof that every
buyout, appraisal, or move has the same result.

## Next test

The decisive extension is a protected buyout ledger joining property appraisal,
offer, negotiation, payment, debt, insurance, moving cost, destination,
household composition, services, health, employment, and later return, staying,
trust, or security.
