# Project: Federal disaster finance, firm reallocation, and flood recovery

## Question

When a large flood occurs, does federal disaster finance merely replace lost
capacity, or can it change which firms, machines, and sources of local income
survive?

## Short finding route

Keep flood exposure, federal declaration and finance, plant exit, credit,
capital reallocation, productivity, county income, worker continuity, and
household recovery as separate stages. This is a Census CES working-paper
result using confidential plant- and county-level data, not proof that every
firm, worker, or resident recovers.

See the [bounded finding](findings/us-census-flood-disaster-aid-firm-reallocation-productivity-2026-001.md).
