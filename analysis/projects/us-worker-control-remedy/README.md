# Project: Worker control, AI exposure, and remedy

## Question

When software or AI changes how work is assigned, monitored, evaluated, or
paid, can workers understand the decision, challenge it, preserve income and
schedule control, and still choose a usable alternative?

## Short end-to-end goal

Follow one worker or workplace episode from system exposure through task and
schedule change, notice, review, remedy, payment or access restoration,
household effect, and later work or exit.

```text
system exposure or work decision
  -> task, pay, schedule, monitoring, or access change
  -> understanding, refusal, appeal, or worker voice
  -> correction, payment, reactivation, or replacement work
  -> household security and durable control
  -> continued work, switching, collective action, or exit
```

This is a separate depth lane in the ongoing 14-theme program. It complements
the broader AI/work project by joining adoption, control, remedy, and later
worker outcomes without pooling unlike case records.

## Current bridge

The [worker control and remedy bridge](worker-control-adoption-remedy-recovery-bridge-v1.md)
compares NBER task adoption, HBS service-work evidence, the ILO platform-work
standard, and named platform-worker remedies. It finds that adoption, formal
review, access restoration, money, and durable work control are separate
currencies.

The new [worker-control stage audit](worker-control-stage-audit-v1.md) compares
measured AI productivity, algorithmic-management exposure, formal rights, and
the one dated reactivation case. It preserves the gap between faster work,
formal review, received remedy, and durable worker power.

The [AI work transition stage audit](ai-work-transition-stage-audit-v1.md)
extends the lane with randomized time effects, task-level adoption, firm
expectations, worker displacement concern, training returns, and bounded public
discussion. It keeps adoption, employer expectation, worker interpretation,
formal preparation, remedy, and later security as separate stages.

## Next test

The next qualifying record is a protected same-worker or workplace episode with
system exposure, decision notice, review authority, pay/schedule effect,
remedy receipt, household consequence, and later work or exit.
