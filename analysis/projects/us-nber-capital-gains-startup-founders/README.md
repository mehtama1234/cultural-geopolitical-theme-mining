# Project: startup founder payoffs, tax design, and risk sharing

This project tracks how capital-gains and wealth-tax design affects founder
ownership, upside concentration, downside insurance, and entrepreneurial
choice. The first bounded record uses NBER Working Paper 34512, combining a
large U.S. venture-backed startup dataset with a dynamic career-choice model.

The project keeps founder, employee, investor, firm, household, and public-
finance consequences separate. A modeled tax tradeoff is not treated as an
observed reform effect or as a complete account of innovation incentives.
