# Project: AI diffusion across firms, functions, and tasks

## Question

Does “a firm uses AI” describe what workers actually do, or are adoption,
business-function deployment, and worker-task use separate stages?

## Decision rule

Keep firm adoption, function deployment, worker task use, augmentation,
headcount, performance, wages, job quality, control, and consumer outcomes
separate. A firm-level adoption number is not a worker-level exposure measure.

## Current bounded finding

The [Census CES finding](findings/us-census-ai-diffusion-firm-function-task-2026-001.md)
reports that firm use, functional deployment, and worker-task use diverge; most
users report augmentation, while employment decreases are rare in the survey
period. This does not settle later labor or social consequences.
