# Project: tariffs, transaction scale, and incidence

## Question

When a tariff changes import prices, who actually absorbs the cost after
transaction size and quantity discounts change?

## Decision rule

Keep statutory tariff, transaction price, quantity discount, exporter markup,
importer cost, retail price, household burden, domestic adjustment, and
geopolitical response separate. Import-price pass-through is not a household
cost estimate.

## Current bounded finding

The [Census CES finding](findings/us-census-tariff-quantity-discounts-incomplete-pass-through-2018-2019-001.md)
reports that observed import prices rose one-for-one with 2018-2019 tariffs,
but after accounting for lost scale economies, strategic pass-through was about
60%, implying foreign exporters absorbed part of the burden through lower
markups.
