# Project: federal performance review and usable institutional learning

This project tests whether government performance frameworks become actual
review, coordination, learning, and changed decisions. It keeps statutory
requirements, guidance, documentation, completed review, management use,
program performance, and public results as separate stages.

The [bounded finding](findings/us-gao-federal-performance-management-strategic-review-2025-2026.md)
uses a 2026 GAO review of OMB and four selected agencies. It is not a complete
scorecard of federal agency performance.
