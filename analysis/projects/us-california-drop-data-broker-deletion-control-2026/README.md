# Project: California's centralized data-broker deletion route

## Question

Does a single privacy request create practical control over data-broker records,
or does it mainly make the request route and its uncertainty more visible?

## Short finding route

Keep eligibility, request submission, hashed matching, broker processing,
exemption/non-match status, deletion, persistence, and consumer burden as
separate stages. This is an implementation and observability finding, not a
consumer-level deletion-success rate.

See the [bounded finding](findings/us-california-drop-data-broker-deletion-control-2026-001.md).
