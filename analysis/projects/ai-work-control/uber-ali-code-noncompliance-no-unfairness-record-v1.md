# Uber Eats / Ali Code-noncompliance and no-unfairness record v1

**Decision:** [2025] FWC 3243, *Hasnain Ali v Portier Pacific Pty Ltd*
(`UDE2025/122`)

**Finding:** the Commission found the deactivation process inconsistent with
the Code but held that the deactivation was not unfair in the circumstances;
the application was dismissed.

## Why this case matters

Ali prevents the atlas from treating Code non-compliance as an automatic
restoration outcome. It adds a distinct merits configuration: the worker was
protected, the process failed the Code, but the Commission still found no
unfair deactivation. Eligibility, process compliance, substantive unfairness,
and remedy are separate questions.

## Primary record

Ali performed delivery work through Uber’s Delivery Platform from 3 April 2024.
His access was deactivated on 29 May 2025 because of low satisfaction ratings.
The Commission accepted that he was an employee-like worker protected by the
statute and heard the Code objection together with the substantive application.

The decision concluded that the deactivation was not consistent with the Code,
but also concluded that it was not unfair in the circumstances. The application
was consequently dismissed. The located decision does not establish
reactivation, lost pay, rating correction, payment, or durable access.

## Stage coding

```text
eligibility                   protected person observed
Code compliance               adjudicated insufficient
substantive unfairness        not established
human review                  process deficient / exact remedy effect open
correction / restoration      not observed
lost pay / compensation       not observed
post-order access             not observed
```

The correct summary is not “the platform won because it followed the Code,” and
not “the worker won because the Code was breached.” It is: the process was
non-compliant, but the unfairness test did not produce a remedy on this record.

## Cross-case use

Read Ali with Abdalla, which supplies a similar non-compliance/no-unfairness
configuration, and with Mohamed, Kumar, and Dar, where rating processes were
found compliant. Read all four against Waheed, Warraich, Khan, and Rehman,
where process and evidentiary deficiencies contributed to restoration or lost
pay. This comparison makes visible that a “human review” or “Code compliance”
field cannot stand in for the complete institutional pathway.

## Open acquisition

Search UDE2025/122 for any appeal, later rating correction, access restoration,
or downstream earnings record. The primary decision contains no implementation
outcome.
