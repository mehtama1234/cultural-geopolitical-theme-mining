# US LRASM Event Zero realization source note

**Checked:** 2026-09-18

## Observed event

The US Air Force Global Strike Command reported that a joint team conducted an
LRASM “Event Zero” at Dyess Air Force Base on 2026-06-02. The event validated
pre-flight procedures for the B-1B aircraft and weapons software using updated
hardware. The team successfully connected a live AGM-158C LRASM to the bomber
using a locally fabricated cable, with the stated purpose of improving future
verification procedures.

**Official source:** [Dyess Airmen validate pre-flight procedures during LRASM
Event Zero](https://www.afgsc.af.mil/News/Article-Display/Article/4538095/dyess-airmen-validate-pre-flight-procedures-during-lrasm-event-zero/)

## Promotion boundary

This is a dated US operational-integration and procedure-validation event. It
advances the realization clock beyond procurement, production support, and
generic flight-science testing. It does not establish an accepted production
quantity, customer delivery, inventory increase, deployment, sustainment,
combat use, or an external actor's response. The local cable is evidence of a
test-specific integration workaround, not proof of broad maintainability or
replaceability.
