# Virginia large-load event-response source note

**Checked:** 2026-09-15  
**Source:** [Virginia SCC SB1239 report](https://www.scc.virginia.gov/media/sccvirginiagov-home/regulated-industries/utility-regulation/responsibilities/scc-report--sb1239.pdf)

## Observation

In its discussion of the July 2024 and February 2025 large-load drop events,
the Virginia State Corporation Commission report records Dominion's account
that customer responses varied: some data centers rode through faults using an
uninterruptible power supply or controller feedback, while others fully
tripped offline after several reclosing cycles. Dominion also stated that
detailed point-of-interconnection data are needed to determine facility
performance during such events.

## Boundary

This adds an observed response pattern at the large-load customer-system level,
not a named-facility performance panel. The report does not provide the
facility roster, event duration by site, household service effect, customer
cost, or a causal estimate of which design or contract term produced the
difference. It does not establish long-run resilience or public legitimacy.
