**Status:** official product-documentation corroboration of available controls;

**Checked:** 2026-09-16

## What the current documentation establishes

Microsoft Learn documentation for Places and Teams describes a technical
control surface that is more specific than the company case narrative alone:

| Control or boundary | Documentation claim | Evidence status |
|---|---|---|
| Automatic update default | Automatic work-location update is off by default and must be enabled/configured by an administrator | Official product documentation |
| User consent and choice | Users must consent to operating-system location access and can opt in or out; users can manually set, override, or clear work location | Official product documentation |
| Admin scope | Tenant administrators can apply different configurations to user groups, including by geography | Official product documentation |
| Inform/Ask/Off modes | Wi-Fi-based updating supports an Inform mode with opt-out, Ask mode with opt-in, and Off mode | Official product documentation |
| Data visibility | The documentation says actual location history is not available and admins do not receive monitoring/reporting views for Automatic Update | Official product documentation |
| Stated purpose | Microsoft describes Automatic Update as collaboration support rather than attendance monitoring or surveillance | Official product documentation; vendor assertion |

## Interpretation boundary

These documents corroborate that user and administrator controls exist in the
current product surface. They do not establish that the 2025 works-council
review caused each control, that every tenant or country uses the same mode,
that workers understood the choice, or that opt-out is consequence-free.
They also do not provide usage rates, audit logs, enforcement records, privacy
incidents, schedule/workload effects, bargaining outcomes, household effects, or
exit.

The correct stage update is therefore:

```text
technical controls documented
  -> historical council intervention partly corroborated at product level
  -> tenant configuration and actual worker exposure [open]
  -> enforceability and worker/household outcomes [open]
```
