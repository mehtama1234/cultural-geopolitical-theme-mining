# Project: delegated medical-device review and public audit capacity

This project tests how a public regulator's delegation of technical review
changes speed, firm access, accountability, and patient-facing assurance.

```text
FDA accreditation
  -> third-party 510(k) review and recommendation
  -> FDA final decision
  -> audit of third-party compliance
  -> device on market
  -> safety, effectiveness, access, and patient experience [open]
```

GAO-26-108499 reaches delegated review and audit-process stages. It does not
follow a device or patient through authorization to later outcomes.
