# Project: Public grant continuity and realized protection

This project follows public-capacity continuity:

```text
grant promise and local project
  -> pause, condition, termination, or deobligation
  -> legal review, restoration, replacement, or abandonment
  -> project delivery and community protection
  -> public legitimacy, trust, and future cooperation
```

It keeps administrative action separate from local outcomes. A grant can be
terminated without proving harm, restored without proving protection, or
continued without proving that the intended project worked.
