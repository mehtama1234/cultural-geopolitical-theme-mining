# Project: Worker remedy, receipt, and durable recovery

## Question

When a worker wins review, back pay, reactivation, or a cross-border labor
remedy, does that result in received money, restored opportunity, durable work,
household recovery, and a usable alternative?

## Working chain

`work or access harm -> notice and contest -> institutional decision -> payment,
correction, or reactivation -> verified receipt and adequacy -> later work,
income, household security, voice, switching, or exit`

## Why this is a separate lane

The existing worker-control project covers AI exposure, worker control, and
formal remedy. This project isolates the next open middle: an order or reported
distribution is not the same as worker-confirmed receipt, restored opportunity,
or durable recovery.

## Next test

Find one authorized same-worker episode with a dated adverse event, notice,
review, remedy decision, receipt, adequacy, later work or household outcome,
and continued use, alternative work, voice, switching, or exit. Preserve
non-return and non-receipt as observed states rather than assuming failure.
