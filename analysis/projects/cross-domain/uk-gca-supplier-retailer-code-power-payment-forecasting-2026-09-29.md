# UK Groceries Code survey: compliance is not the same as supplier room

## Finding

The UK Groceries Code Adjudicator’s 2026 annual supplier survey adds a
firm-sector version of the project’s optionality finding. Average perceived
compliance across the 14 designated retailers remained high at 92%, and more
than half of suppliers reported no issue. But the share reporting a Code issue
rose from 30% to 32%.

The issue categories show where formal compliance can leave practical room
tight: 20% reported problems with promptly resolving invoice discrepancies, 18%
reported significant costs from inaccurate forecasting, 15% reported
de-listing without reasonable notice, and 14% reported payment delays. The
regulator’s confidential and anonymous reporting channels create a route for
voice, but the public release does not show whether a supplier received payment,
correction, compensation, continued listing, or improved bargaining power.

The cross-source implication is that supply-chain power is experienced through
timing, information and exit—not only through whether a code is formally
followed. These supplier conditions can eventually affect prices, product
availability, innovation and consumer choice, but those downstream effects are
not observed here.

## Boundary

This is aggregate, publisher-reported evidence from a confidential supplier
survey. The official release does not provide response rate, weighting,
supplier-size composition, confidence intervals, contract records, retailer
responses, monetary losses or completed remedies. It is not a consumer survey,
legal finding, or causal estimate.

Source: [Groceries Code Adjudicator, High Code compliance maintained as some
supplier issues increase](https://www.gov.uk/government/news/high-code-compliance-maintained-as-some-supplier-issues-increase).
