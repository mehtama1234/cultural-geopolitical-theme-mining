# Critical minerals, substitution, and strategic dependence

This project examines the material layer beneath batteries, semiconductors, defense systems, grids, data centers, and consumer electronics. It keeps mineral import reliance, processing concentration, recycling potential, substitution, domestic research, and geopolitical leverage as separate stages.
