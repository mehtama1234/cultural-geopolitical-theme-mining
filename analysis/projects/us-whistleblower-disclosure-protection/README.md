# Project: whistleblower disclosure and public accountability

This project tests when worker and public information becomes usable oversight.
It keeps disclosure, confidentiality, retaliation protection, agency capacity,
investigation, remedy, enforcement, recurrence, and trust as separate stages.

The [bounded finding](findings/us-gao-whistleblower-disclosure-protection-agency-capacity-2026.md)
uses a 2026 GAO review of selected federal agencies and organizations. It is
not a national whistleblower rate or a complete measure of agency performance.
