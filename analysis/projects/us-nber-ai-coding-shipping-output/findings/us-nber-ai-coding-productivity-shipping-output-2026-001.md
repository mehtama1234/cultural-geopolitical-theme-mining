# Finding: AI coding activity rises faster than shipped and used software

**Status:** bounded AI-production and firm-capacity finding · **Checked:** 2026-09-23

## The bounded finding

NBER Working Paper 35275 combines data on more than 500,000 GitHub developers
with AI usage telemetry. In a matched event-study design, the paper reports
cumulative increases in coding activity of 30% for autocomplete tools, 180%
for interactive coding agents, and 240% for autonomous coding agents.

The gains attenuate across the production hierarchy: the 240% increase in
commits associated with autonomous agents falls to 80% for projects and 30%
for actual releases. Across four software marketplaces, the number of new
apps rises but total usage does not. The paper estimates an elasticity of
substitution of 0.23 between AI and human effort, consistent with strong
complementarity.

The atlas-relevant insight is:

> A tool can increase visible task activity without producing a proportionate
> increase in shipped or used output. Human review, coordination, demand,
> quality, security, and other production stages remain part of realized
> capability.

## Limits and next test

- The abstract does not establish that every tool-adoption association is
  causal for every developer or firm.
- Commits, projects, releases, and marketplace usage are different units and
  must not be collapsed into one productivity measure.
- The evidence does not establish code quality, worker wellbeing, pay,
  bargaining power, consumer value, or firm survival.
- The next test is a named-team ledger joining tool exposure, task mix, review
  and security time, release persistence, quality, worker compensation, and
  user adoption.
