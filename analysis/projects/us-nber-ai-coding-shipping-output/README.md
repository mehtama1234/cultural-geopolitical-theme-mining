# Project: AI coding activity, production bottlenecks, and realized output

This project tracks the path from AI-enabled task activity to projects,
releases, usage, worker control, and firm or consumer consequences. The first
bounded record uses NBER Working Paper 35275, which links GitHub developers to
AI usage telemetry and compares coding activity with downstream production
stages.

The core distinction is activity versus realization. A large increase in
commits is not treated as equivalent to shipped software, user adoption,
quality, worker gains, or firm productivity. Future passes should add named
teams, task mix, review and security work, quality, release persistence,
worker time and pay, and consumer usage or value.
