# Project: organized interests and gun-policy responsiveness

This project tests when organized political resources, party control, and
constituent sentiment translate into state policy. It keeps campaign money,
public opinion, legislative change, implementation, safety, and legitimacy as
separate stages.

The [bounded finding](findings/us-nber-organized-interests-gun-policy-responsiveness-2000-2024.md)
uses a 2026 NBER state-level study as a political-institutional source. It is
not a universal claim about all policies or all democratic representation.
