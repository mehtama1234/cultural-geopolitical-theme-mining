# Project: national-lab partnership capacity

## Question

When national laboratories do paid work for other agencies and partners, does
that strengthen the national-security system or compete with core mission
capacity?

## Decision rule

Keep reimbursed work, facility use, staffing, mission support, cost recovery,
technical output, readiness, and geopolitical effect separate. Partnership
volume is not the same as delivered capability.

## Current bounded finding

The [NNSA partnership finding](findings/us-gao-nnsa-strategic-partnership-projects-capacity-2019-2024-001.md)
shows almost $15 billion in reimbursed project work across eight NNSA sites,
with reported mission and workforce benefits alongside uneven site capacity.
The net effect on core missions and partner capability remains open.
