# Project: gender gaps in career information and advice

This project follows an often-hidden allocation mechanism: student identity →
information received from professionals → work-life-balance beliefs and career
intentions → education, occupation, earnings, care, and household outcomes. It
keeps information access, intention, and realized career separate.

The first bounded finding uses NBER Working Paper 35750. In a large field
experiment involving 10,000 working professionals, female college students
received substantially more work-life-balance information than male students,
even when students explicitly asked about that topic. An information
intervention indicates that the gap is consequential for gender differences in
career intentions.
