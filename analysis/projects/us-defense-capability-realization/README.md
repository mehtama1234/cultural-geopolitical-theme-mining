# Project: Defense procurement to usable capability

## Question

When a state signs a defense contract, how does that become delivered,
accepted, trained, maintained, operational capability and changed external
behavior rather than a financial or political signal only?

## Working chain

`threat or strategic concern -> authorization and contract -> production and
shipment -> acceptance and integration -> training, maintenance, and readiness
-> replaceability and operational use -> alliance, adversary, and public
response`

## Relationship to existing research

The military-readiness and procurement work already covers spending, award
structure, production, and broad capability language. This is a separate depth
lane for the middle between contract and operational leverage, with Poland's
JASSM-ER order as the anchor and F-35/LRASM and NATO medical readiness as
bounded comparators.

## Next test

Locate an identifier-bearing order, shipment, acceptance, training, maintenance,
and operational-use record for one system and recipient. Then compare the dated
capability change with an external actor's observed response. Preserve
non-observation as a bounded public-source result.
