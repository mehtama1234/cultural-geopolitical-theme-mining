**Checked:** 2026-09-20  
**Status:** breadth-preserving route decision; no new reader finding promoted

## Question

Which retained source can add a genuinely new bridge across the current
rotation: material pressure -> time/care or movement response -> later
household, service, or institutional consequence?

The promotion rule is narrow. A candidate must add a new unit, mechanism, or
stage. Another cross-sectional pressure/adaptation table is useful context but
is not a new atlas finding.

## What the screen says about the broader atlas

The recurring pattern is not simply “people face pressure.” It is that
pressure is converted through different currencies:

```text
material shock or low room
  -> substitution, reduced use, delay, borrowing, extra work, unpaid care,
     non-use, or movement
  -> protected current need / sacrificed future room
  -> institutional response and practical receipt
  -> later security, trust, collective action, switching, or exit
```

The retained sources observe different pieces of this chain and should remain
separate. Extra work is not proof of improved security; reduced paid care is
not proof of lower need; benefit receipt is not proof of usable care; a named
service site is not a completed appointment; and a later health or employment
observation is not event-specific recovery.

## Route decision

No new reader heading is justified by this screen. The existing reader already
covers these mechanisms through the material-adaptation, care, public-system,
place, and event-spine findings. The next meaningful depth pass is:

1. restore the authorized MEPS staging inputs, if they are legitimately
   available, and rerun only the event-compatible fields; or
2. use a user/account-holder supplied UAS file under terms that expressly
   authorize the workflow, beginning with identity, overlap, timing, weights,
   missingness, and remedy-field audits.

Until one of those routes is available, the correct output is a bounded
acquisition boundary—not a pooled pressure-to-recovery estimate.

## Storage and compliance boundary

This screen uses committed compact outputs and existing project notes only. It
does not download respondent files, reconstruct the missing MEPS staging file,
or access UAS data. No new person-level estimate is produced.
