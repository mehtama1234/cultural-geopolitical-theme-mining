# US ACS transportation context

This project supplies an independent annual household/worker frame for the
mobility and time-burden lane. It is intentionally separate from NHTS:
ACS provides annual aggregate household and commuting estimates, while NHTS
provides sampled household, person, and travel-day records.

The current analysis is documented in the [annual national layer](../us-household-calendar-integration/acs-transport-annual-national-layer-v1.md)
and preserved in the [trend record](../../records/us-acs-transport-annual-national-2023-2024.json).
