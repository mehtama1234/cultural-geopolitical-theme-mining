# Project: US platform data retention and practical control

## Question

What happens to user and non-user data after it enters large social and video
platform systems?

## Decision rule

Keep collection, inference, sharing, retention, deletion request, actual
deletion, security, and user control separate. A privacy setting or request
route is not proof that data disappeared or that the person regained control.

## Current bounded finding

The [FTC finding](findings/us-platform-data-retention-control-001.md) shows
that large platforms can offer privacy controls while their reported data
collection, sharing, retention, and deletion practices leave practical control
uncertain.
