# Project: Data-center load, grid reliability, and public legitimacy

## Question

When large computational loads create operating, cost, or environmental
pressure, do grid rules and benefit-sharing produce reliable service, fair
household incidence, and durable community consent?

## Working chain

`large-load growth -> interconnection and operating exposure -> event or
capacity response -> cost/reliability/environmental allocation -> household
experience and local voice -> facility compliance, acceptance, adaptation, or
political conflict`

## Relationship to existing research

The AI and infrastructure work already covers data-center capacity, revenue,
cost-allocation proposals, and governance records. This is a separate depth
lane for the missing conversion from a real operating event and formal rule to
measured household incidence and legitimacy.
