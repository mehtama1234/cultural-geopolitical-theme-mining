# Company trend-intelligence implementation checklist

This is the current evidence-backed handoff for the new goal. A checked item
means the repository contains the artifact and validation named in the last
column; it does not mean company-specific impact has been proven.

| Requirement | Current evidence | Verification |
|---|---|---|
| Governing company-facing goal | `COMPANY_TREND_INTELLIGENCE_GOAL_V1.md` | Goal names the evidence chain, 14 themes, business translation, and limits |
| Source-traceable trend records | Eight Markdown records with source packets, methods, limits, and next tests | Portfolio validator checks IDs, titles, source links, and committed source packets |
| Business translation | Each record has customer, workforce, product, finance, operations, institutional, reputation, and geopolitical exposure | Validator checks the business-exposure section |
| Cross-domain interpretation | Each record has cultural, financial, institutional, and geopolitical interpretation | Validator checks the explicit section |
| Three horizons | Each record has now, next, and longer-term implications | Validator checks all three horizon labels |
| 14-theme scope control | Markdown, JSON, and CSV coverage matrix | Validator checks exactly 14 themes and matching JSON/CSV numbers |
| Visual frontend | JSON-backed board with domain, confidence, horizon, and 14-theme charts | Local HTTP smoke test loads the board and portfolio |
| Management operating rhythm | Decision playbook with weekly, monthly, quarterly actions and ownership | Playbook defines action, evidence, ownership, and review boundaries |
| Future work discipline | Next-record queue for health/care, time/care, and concentration themes | Queue defines evidence required before promotion |

## What is still open

- Company-specific causal impact, ROI, readiness, safety, and deployment remain
  unproven until a downstream company names the tests and returns evidence.
- Health, disability, aging, and care now has a qualified record, but its
  company-specific outcome remains open until a named workflow is tested.
- The current worktree contains unrelated pre-existing source deletions; this
  checklist does not restore or reinterpret them.
