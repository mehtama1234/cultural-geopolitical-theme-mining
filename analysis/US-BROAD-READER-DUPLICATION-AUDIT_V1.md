# Broad reader duplication audit v1

**Checked:** 2026-09-21  
**Purpose:** keep the communication layer broad without mistaking repeated
promotion for new evidence.

## Current result

The reader contains **367 numbered headings** and **367 distinct heading
titles** after the title-level cleanup in this pass. Earlier versions had five
repeated title patterns:

| Repeated title | Occurrences |
|---|---:|
| Health-care capacity can fail at the accessibility interface | 2 |
| Semiconductor funding can advance while strategic independence remains unsettled | 2 |
| Shared moral pessimism does not produce a shared public remedy | 3 |
| The AI distribution problem starts before displacement | 2 |

This was a communication-layer duplication, not evidence that the underlying
records, observations, or event ledgers are duplicated. Some repeated sections
were written at different synthesis stages and may contain different wording or
source links, but the title-level audit cannot assume they are substantively
distinct.

## Operating rule

Future promotions must first search the reader by source path, title, and the
finding's distinctive numbers. A candidate that is already represented should
be linked into an existing section or used to deepen a synthesis, not given a
new numbered heading. A genuine new finding should add a new mechanism, unit,
or cross-domain bridge.

## Cleanup boundary

The five title groups were renamed where their evidence emphasized a distinct
measurement or mechanism. This does not prove that every section is fully
non-overlapping in substance; the next cleanup should compare source paths and
numbers before merging any prose. The current numbered count is an index count
and should not be treated as a pooled estimate.

example and should prefer synthesis links when no new unit, mechanism, or
stage is added.
