# Ongoing Cultural, Social, and Geopolitical Theme Mining

**Status:** active, recurring program
**Started:** 2026-10-18
**Scope:** all 14 atlas themes and the full registered source universe

## The standing goal

Keep reviewing the atlas's research papers, surveys, administrative records,
public records, company and market evidence, infrastructure data, cultural
measures, opinion data, and geopolitical sources. Extract their important data
points, compare them across source families, identify recurring cultural and
geopolitical patterns, test counterexamples, add bounded public discussion, and
select the next highest-learning research question.

This is a continuing program. A completed pass, source packet, theme wave, or
social-augmentation batch is not completion of the program.

## How each pass will work

Every pass follows the same loop:

```text
select the thinnest or most consequential open arrow
  -> review primary and authoritative source records
  -> extract unit, population, place, date, measure, denominator, and limit
  -> compare at least two different source families
  -> add a distributional cut or a real counterexample
  -> trace the next actor, response, remedy, or practical consequence
  -> add bounded public discussion from YouTube, Reddit, LinkedIn, and X
  -> write what is supported, inferred, and still open
  -> define the next stronger test
```

The basic evidence card is:

```text
source -> unit and window -> measured change -> mechanism stage
       -> affected group/place -> response or adaptation
       -> downstream result -> counterexample -> missing link -> next test
```

## Source discipline

Use the registered source universe, with NBER, HBS, academic repositories,
official statistics, surveys, administrative records, company filings,
infrastructure records, cultural measures, and geopolitical records all treated
as distinct evidence layers. They are complementary, not interchangeable.

Do not combine unlike records into one statistic. Keep respondent, household,
worker, customer, case, firm, agency, place, market, platform, and state units
separate. Label every claim as observed, reported, estimated, compared,
inferred, or open.

## First depth rotation

The first active route is **public-system usability and practical security**:

```text
need or eligibility
  -> notice, paperwork, interview, deadline, or route effort
  -> approval, denial, interruption, or continued receipt
  -> benefit timing and amount
  -> food, housing, utility, work, health, and care security
  -> remedy, fairness, trust, complaint, political response, or exit
```

The existing SNAP/public-system work is the starting base. The first pass will
compare USDA/FNS route performance, Urban WBNS lived barriers, NBER mechanism
studies, SIPP same-person transitions and hardship, care/work layers, and
public-system or consumer social discussion. The pass must preserve the fact
that these sources do not yet form one linked case.

The pass is successful when it produces one durable evidence artifact with:

1. a cross-source comparison;
2. a measured distribution or counterexample;
3. a clear account of what the route does and does not show;
4. a bounded social-meaning layer;
5. an explicit missing middle stage; and
6. a stronger next acquisition or longitudinal test.

## Rotation across the 14 themes

After one depth artifact, rotate to the lane with the fewest measured arrows:

1. material and time — household room, time, care, unequal exposure;
2. consumer, platform, and work power — recourse, platforms, work, firms;
3. place, public systems, and politics — housing, public systems, action;
4. meaning, infrastructure, and state consequences — identity, infrastructure,
   geopolitics.

Each rotation must add a different source family, unit, geography, period,
subgroup, or counterexample. If the needed data are unavailable or access is
controlled, record the gap and move to the next useful route instead of
pretending that another aggregate closes it.

## Promotion and stopping rules

Promote a recurring trend only when at least two compatible source layers point
to it, the units and limits are visible, it survives a subgroup or place check,
and the next stronger test is named. Stop a pass when the remaining evidence is
only a repeated announcement, geographic coincidence, or unmeasured inference.

The program remains active after every pass. The durable output is the updated
evidence map, trend register, counterexample register, social-discussion layer,
and next-pass queue.
