MEPS 2025 release-boundary audit — 2026-09-15

Status: official release-index check; no 2025 full-year public-use file located

Acquisition question

Can the current 2024 MEPS event/payment bridge be extended with a 2025 full-year consolidated file and corresponding event files?

Official index result

The AHRQ MEPS public-use download index was checked on 15 September 2026. Its searchable release range is listed as 1996–2024. The consolidated-file results identify HC-256 as the 2024 Full Year Consolidated Data File and HC-252 as the 2022–2023 Panel 27 Longitudinal Data File; no 2025 HC-257 consolidated file is listed.

The latest 2024 event-file pages remain available, including the HC-254 series. The HC-254H page identifies the 2024 Home Health File and says it was released in May 2026. This confirms that the 2024 release family is still the current public-use endpoint for the episode analysis.

Consequence for the end-to-end goal

The project should not claim a 2025 MEPS year-over-year extension or fabricate an HC-257 path. The current evidence boundary is:

2024 HC-256 person context
  + 2024 HC-254 event files
  + 2022–2023 HC-252 longitudinal panel
  -> current public MEPS endpoint

The 2024 MEPS event ledger can still be deepened through additional event families, stricter timing, and exact person/event linkage. But a newer MEPS calendar year cannot currently supply the missing bill-to-choice-to-recovery join.

Next acquisition decision

  1. Continue the 2024 MEPS event-family analysis only where the event file and HC-256 linkage are documented.
  2. Use SHED for 2025 care-foregoing and household adaptation, explicitly as a different annual respondent design.
  3. Pursue UAS or HRS registration/microdata access for a dated health-cost, outcome, and legitimacy sequence.
  4. Recheck the AHRQ release index after the next annual update; record a new dated audit before promoting any 2025 MEPS result.

Boundary

This is a release-availability finding, not evidence that no 2025 MEPS data exist internally or that a future release will not appear. It establishes only that no 2025 full-year public-use consolidated file was listed on the checked official index on 15 September 2026.
